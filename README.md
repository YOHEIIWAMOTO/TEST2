# TEST2

## 修正: デスクトップ版セッション履歴が保存されない問題

### 問題

デスクトップ版でセッション履歴が残らない問題が発生していた。

**根本原因:** セッション履歴の書き込みが非同期(`fs.writeFile`)のみで実装されていたため、
アプリケーションプロセスが終了するタイミングで書き込みが完了する前にプロセスが終了し、
データが失われていた。

### 修正内容

`src/session/SessionHistoryManager.ts` に以下の修正を実装:

1. **`flushSync()` の追加**: プロセス終了時(`exit`, `SIGINT`, `SIGTERM`)に
   同期書き込み(`fs.writeFileSync`)で確実にデータを保存するようにした。

2. **アトミックな書き込み**: `.tmp` ファイルへの書き込み後に `rename` することで、
   中断時のファイル破損を防ぐ。

3. **ディレクトリ自動作成**: 保存先ディレクトリが存在しない場合に自動作成するように修正。

4. **デバウンス処理**: 頻繁な更新時の I/O 負荷を軽減するデバウンス機能を追加。

### 修正ファイル

- `src/session/SessionHistoryManager.ts` - セッション履歴管理クラス
- `src/session/SessionHistoryManager.test.ts` - テストコード
