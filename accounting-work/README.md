# accounting-work - 経理業務プロジェクト

経理業務を効率化するためのプロジェクトフォルダです。
Claude Code と連携して、日常の経理タスクを自動化・管理できます。

---

## フォルダ構成

| フォルダ | 用途 |
|---|---|
| `tasks/毎月-経費精算/` | 毎月の経費精算に関するタスクファイルを格納します。領収書の集計や精算書の作成手順などを管理します。 |
| `tasks/毎月-仕訳入力/` | 毎月の仕訳入力に関するタスクファイルを格納します。勘定科目の対応表や入力ルールなどを管理します。 |
| `tasks/毎月-月次決算/` | 毎月の月次決算に関するタスクファイルを格納します。決算チェックリストや締め作業の手順を管理します。 |
| `receipts/` | レシート・請求書の PDF を置く場所です。ファイル名は `YYYY-MM-DD_取引先名_金額.pdf` のように統一すると検索しやすくなります。 |
| `bank-statements/` | 銀行の通帳データ（CSV）を置く場所です。ネットバンキングからダウンロードした明細をここに保存します。 |
| `scripts/` | 自動化スクリプトを格納します。CSV の変換、仕訳データの生成、レポート作成などのスクリプトを配置します。 |
| `reports/` | 月次レポートの出力先です。生成されたレポートや集計結果がここに保存されます。 |
| `templates/` | 会計ソフトへのインポート用テンプレート（CSV テンプレートなど）を格納します。 |
| `.claude/skills/` | Claude Code 用のカスタムスキル定義を配置します。 |

## はじめて使う方へ

1. **レシートや請求書** を受け取ったら `receipts/` フォルダに PDF を保存してください。
2. **銀行明細** をダウンロードしたら `bank-statements/` フォルダに CSV を保存してください。
3. 毎月のタスクは `tasks/` 配下の各フォルダにある手順に沿って進めます。
4. `scripts/` 内のスクリプトを使うと、CSV 変換やレポート生成を自動化できます。
5. 生成されたレポートは `reports/` フォルダに出力されます。

## ファイル命名規則（推奨）

- レシート: `YYYY-MM-DD_取引先名_金額.pdf`
- 銀行明細: `YYYY-MM_銀行名.csv`
- レポート: `YYYY-MM_レポート名.xlsx`
