# 消費税区分

| 区分 | 税区分 |
|---|---|
| 国内仕入 | 課対仕入10% |
| 軽減税率対象（食品等） | 課対仕入8% |
| 海外SaaS | 課税対象外（リバースチャージ） |
| 給与・社会保険 | 対象外 |

## プロジェクト概要

- 毎月の経費精算、仕訳入力、月次決算をサポート
- レシート・請求書の管理
- 銀行明細（CSV）の取り込みと処理
- レポートの自動生成

## フォルダ構成ルール

- `receipts/` にはPDFファイルのみ配置する
- `bank-statements/` にはCSVファイルのみ配置する
- `reports/` 内のファイルはスクリプトで生成する（手動編集しない）
- `templates/` のテンプレートを変更する場合は既存のインポート処理に影響がないか確認する
